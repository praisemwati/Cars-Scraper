# Cars Web Scraper

An automated web scraping pipeline built to extract
cars listings from Classfieds.co.zw Cars using 
Playwright, BeautifulSoup and bot-detection evasion 
techniques.

---

## Project Overview

This project automates the extrction of cars listings
e.g(Classifieds Cars data) for market analysis and price 
tracking . It handles dynamic JavaScript rendering and 
anti-bot measures to deliver structured output in CSV format.

---

## Tech Stack & Tools

***Language:** Python 3.x
***Browser Automaton:** [Playwrigtht](https://playwright.dev/python/)(Headless browser automation)
***Anti-Bot Evasion:** 'playwright' (Bypasses bot-detection mechanics)
***Parsing:** [BeautiulSoup4](https://www.crummy.com/software/BeautifulSoup/bs4/doc/)
(Fast HTML tree Parsing)
***Data Output:** CSV
